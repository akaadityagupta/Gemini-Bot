# Gemini-Bot

A Python-based conversational AI bot powered by Google's Gemini 1.5 Flash model with text-to-speech capabilities.

## About Generative AI

Generative AI refers to artificial intelligence systems that can create new content, including text, images, code, and more. These systems learn patterns from existing data and use that knowledge to generate new, original content.

### Key Concepts

1. **Large Language Models (LLMs)**
   - Neural networks trained on vast amounts of text data
   - Can understand and generate human-like text
   - Examples: GPT, Gemini, BERT, etc.

2. **Key Capabilities**
   - Text generation
   - Conversation
   - Content summarization
   - Language translation
   - Code generation
   - Question answering

3. **Applications**
   - Chatbots
   - Content creation
   - Virtual assistants
   - Code assistance
   - Educational tools
   - Creative writing

## About This Project

This project implements a conversational AI bot using Google's Gemini 1.5 Flash model with the following features:

- Interactive text-based conversation
- Text-to-speech output
- Simple and user-friendly interface

### Prerequisites

- Python 3.x
- Google API key for Gemini
- Required Python packages:
  - google.generativeai
  - pyttsx3

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Gemini-Bot.git
```

2. Install required packages:
```bash
pip install google.generativeai pyttsx3
```
3. Configure API key:
   - Get your API key from Google AI Studio
   - Replace "Your_API_KEY" in main.py with your actual API key

### Usage

1. Run the program:
```bash
python main.py
```

2. Interact with the bot through the command line. Type your message and press Enter to receive a response. Type 'exit' to quit the program.

2. Enter your prompts when you see "You: "
3. Type 'exit' to end the conversation

### Features

1. **Text Generation**
